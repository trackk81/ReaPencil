# ReaPencil 0.8.61 — 일반 프리뷰 선폭·알파 곡선

Maya 2025 / Windows x64용 업데이트입니다. 최종 렌더는 기존 CPU 방식을 유지합니다.

- 일반 **ReaPencil Preview**에서 획을 따라 변하는 선폭·알파 곡선을 표시합니다. Linear, Bezier, Spline, Break와 획 방향·분할·폐곡선 규칙을 반영합니다.
- **프리뷰 성능 설정 → 선폭·알파 곡선 표시**에서 화면 표시만 켜고 끌 수 있습니다. 기본값은 켜짐이며 CPU 렌더에 저장된 곡선은 바뀌지 않습니다.
- 독립 획은 GPU에서 평가하고, 연결 획은 메시·스타일별 병렬 계산과 기하·곡선 캐시를 사용합니다. 화면 밖 메시의 생략 전후 결과도 비교 검증했습니다.
- 0.8.59에서 발생하던 일반 프리뷰의 잡선과 MSAA 선 잘림을 함께 수정했습니다. MSAA를 끄거나 전역 깊이 바이어스를 키우는 방식으로 처리하지 않았습니다.
- 한국어 곡선 버튼과 제목을 정리했습니다. 예전 단일 계수는 **이전 방식 선폭 감소 (CPU)**, 시작·종료 거리 방식은 **카메라 깊이별 감소**로 구분합니다.

## 실제 Maya 검증과 성능

열린 메시의 분할각·폐곡선 방향·MSAA 0/8배, 서로 다른 라인셋, 화면 밖 오브젝트의 재진입, 차폐면을 검사했습니다. 통제 장면의 곡선 선폭은 CPU 결과와 약 0.011픽셀 이내로 일치했습니다. 설치 파일 134개와 검증한 로컬 런타임의 해시가 같고, 기존 CPU 곡선 테스트 PNG도 바이트 단위로 같습니다. 고속 프리뷰는 변경하지 않았습니다.

프레임버퍼 읽기를 포함한 카메라 이동 측정에서 열린 메시 장면은 곡선 미표시/표시 모두 약 123fps, 20,200개 선 장면은 약 100→95fps였습니다.

**대형 장면의 전체 곡선 표시에는 성능 비용이 남습니다.** 418만 개 후보 선의 고밀도 장면에서 카메라 회전은 미표시 약 73~84fps, 전체 곡선 표시 약 26~30fps였습니다. 이는 해당 구도·하드웨어의 측정값이며 모든 장면의 속도를 보장하지 않습니다. 복잡한 장면에서는 필요한 라인셋에만 곡선을 적용하거나 프리뷰 표시 옵션을 꺼서 비용을 줄일 수 있습니다. CPU 렌더의 선 품질을 낮추거나 선을 간소화하지 않았습니다.

일반 프리뷰의 retained OpenGL Core 경로를 대상으로 합니다. 숨은 선·대시·예전 계수식 거리 감소·Merge Groups 등 기존 legacy 경로가 필요한 조합에는 동일한 곡선 표시를 아직 보장하지 않습니다. 끝 가늘게·굵기 변화·Pencil+ 선폭 커널 보정은 기존대로 CPU 전용이며, 카메라 평면을 가로지르는 획은 곡선 검증 범위 밖입니다.

## 설치

아래 **ReaPencil-0.8.61-Maya2025-Windows-x64.zip**을 내려받아 전체 압축을 풀고 `INSTALL.cmd`를 실행한 뒤 Maya를 다시 시작하세요. GitHub가 자동 생성한 Source code ZIP은 설치 파일이 아닙니다. 기존 설치본은 ReaPencil의 업데이트 확인을 사용할 수 있습니다.

PSOFT 원본 플러그인·바이너리·셰이더·라이선스 코드는 포함하지 않습니다. 제3자 의존성의 고지는 패키지에 유지했습니다.
