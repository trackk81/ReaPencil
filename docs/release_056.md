# ReaPencil 0.8.56

Maya 2025 / Windows x64용 업데이트입니다. 로컬에서 확인한 0.8.56의 검증된 런타임을 배포합니다.

## 변경 사항

- **일반 프리뷰에서 카메라 깊이별 선폭 감소**를 표시합니다. 가까운 곳은 두껍고 먼 곳은 얇게, 하나의 긴 선 안에서도 연속적으로 변합니다. 현재 카메라 행렬을 GPU에서 사용하므로 카메라 이동 때 이 효과를 위해 선 버퍼를 다시 만들지 않습니다.
- 거리별 감소 창에 **선택 오브젝트로 선폭 거리 채우기** 버튼을 추가했습니다. 현재 뷰포트 카메라 기준으로 선택한 메시 버텍스의 가까운·먼 깊이를 측정해 시작·종료 거리에 넣습니다. 단위는 cm입니다. 선폭 감소가 꺼져 있으면 켜며, 두께 배율은 유지합니다. **적용**을 눌러 저장합니다.
- 선폭 측정 버튼은 위쪽 하나로 정리했습니다. 알파 감소용 측정 버튼은 별도로 유지합니다.
- 한글 설정에서 측정 버튼이 영어로 나오던 문제와 이전 번역 목록이 메모리에 남아 있던 경우를 수정했습니다. 열린 창의 한글·영문 전환 시 편집 중인 값은 유지합니다.

## 사용과 범위

라인 창에서 라인셋을 선택하고 **거리별 감소(CPU)**를 엽니다. 메시를 선택한 뒤 위쪽 측정 버튼을 누르고 시작·종료 배율을 조절한 다음 적용하세요. 마지막으로 사용한 뷰포트 카메라가 측정 기준이며 창에 카메라 이름과 거리가 표시됩니다. 측정은 버튼을 누를 때만 실행됩니다.

일반 프리뷰의 지원 범위는 **OpenGL Core의 retained GPU 경로에서 카메라 깊이에 따른 가시 선폭 감소**입니다. 고속 프리뷰, 알파 감소, 참조 오브젝트 기준 감소와 legacy 경로의 고급 스타일은 이번 확장에 포함하지 않았습니다. 최종 CPU 렌더는 기존 방식을 유지합니다. 카메라를 바꿔 렌더할 때는 그 카메라에 맞는 범위를 확인하세요. 종료 배율 0이면 먼 선은 사라집니다.

## 검증

- 별도 Maya에서 실제 버튼 클릭, 한글·영문 표시 및 실시간 전환, 카메라 우선순위, 측정·적용·취소·Undo, 선택 유지와 잘못된 선택 처리를 확인했습니다.
- 변환·계층·인스턴스와 표시 단위가 m인 장면에서도 내부 cm 기준 측정을 확인했습니다.
- 대형 도시 장면 약 691만 삼각형·1,317만 선분, Ryzen 9 7900X / RTX 4070, 일반 프리뷰 1445×845에서 카메라 회전과 GPU 화면 읽기를 포함해 각 모드 3회 측정: 깊이 감소 끔 중앙값 약 45.1fps / 켬 약 45.4fps. 큰 저하는 관측되지 않았으며 차이를 고유한 성능 향상으로 해석하지 않습니다. 장면·선폭·하드웨어에 따라 결과는 달라집니다.
- 깊이 설정 적용 전후의 CPU 회귀 결과를 확인했으며, UI 수정 후에도 기존 CPU PNG 해시가 동일했습니다.

## 설치 / 업데이트

기존 설치에서는 **ReaPencil → 업데이트 확인 → 다운로드 및 설치 예약**을 사용하세요. 작업을 저장하고 Maya를 종료한 뒤 설치를 마치고 다시 실행합니다. 다른 PC에서도 GitHub 로그인 없이 업데이트할 수 있습니다.

처음 설치할 때는 **ReaPencil-0.8.56-Maya2025-Windows-x64.zip** 전체를 풀고 **INSTALL.cmd**를 실행하세요. GitHub의 자동 생성 Source code ZIP은 설치 파일이 아닙니다. 사용자 장면과 원본 Pencil+ 바이너리·라이선스는 포함하지 않습니다.
