# ReaPencil 0.8.8

- Smooth 설정을 바꿀 때 입력이 그대로인 다른 메시의 평가 결과와 연결 정보를 재사용합니다. 원본 정점, 월드 변환, 스무스 옵션과 크리즈를 검사하며, 재질·토폴로지 변경은 전체 재계산으로 처리합니다.
- 메시가 움직이거나 변형될 때 변경된 메시의 선 데이터만 갱신합니다. 고정된 에지의 연결 정보는 유지하고, 위치와 면 법선은 네이티브 코드로 갱신합니다.
- GPU 교차선은 변경된 메시와 관련된 쌍을 다시 검사합니다. 작은·중간 장면에서 불필요한 페이지 분할과 GPU 후보 배열의 왕복 전송을 줄였습니다. 256개를 넘는 메시에는 기존 메모리 제한 경로를 유지합니다.
- GPU 화면 표시 보조 모듈은 **reaPencilDraw088.mll**입니다. 메인 플러그인 **reaPencil.py**가 자동으로 불러옵니다. 업데이트 적용 후 Maya를 다시 실행하세요.
- 최종 렌더는 기존 CPU 방식을 유지합니다. 사용자 장면의 Smooth 수준을 낮추거나 원본 파일을 저장하지 않습니다.

실제 Maya 2025 / RTX 4070 / 1757×1044 뷰포트에서 123개 메시를 표시한 테스트 결과입니다. Smooth 2 적용 시 몸통 갑옷은 2.91초에서 1.82초, 머리카락은 2.49초에서 1.40초로 줄었습니다. 캐시를 사용한 화면 RGB는 전체 재계산 결과와 일치했습니다.

원래의 스무스 설정을 유지한 팔 그룹 움직임은 약 29fps였고, 카메라 회전은 30fps를 넘었습니다. 어깨에 Smooth 2를 추가한 Blend Shape 변형은 약 1.3fps에서 23fps로 개선됐지만 아직 30fps에 미치지 못합니다. 장면에 실제 리깅·애니메이션 키가 없어 별도로 만든 그룹 움직임과 메시 변형으로 검증했습니다. 모든 리깅과 변형에서 30fps를 보장하는 것은 아닙니다.
