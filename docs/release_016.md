# ReaPencil 0.8.16 — CPU 렌더 최적화 (로컬 검증본)

- Maya의 변경 알림과 실제 메시 평가를 확인해 변하지 않은 스무스 형상, 엣지 정보와 BVH를 재사용합니다. 메시·부모 변환·스무스 설정·리깅 결과가 바뀌면 해당 데이터를 갱신합니다.
- 교차선 질의는 형상 세대, 가시성 마스크, 허용 오차와 작업 한도가 모두 같은 경우에만 재사용합니다. 선 색상과 라인셋 적용은 매번 새로 계산합니다.
- 교차선 결과를 배열로 전달해 수만 개 Python 레코드 생성과 변환을 줄였습니다. 기존 선 합성 순서를 유지합니다.
- CPU 안티앨리어싱 축소 필터와 이미지 메모리 사용을 개선했습니다.
- 네이티브 메시 추출기의 명령 구문 객체가 인자 조회 전에 소멸할 수 있던 수명 문제를 수정했습니다.
- 형상 및 파생 데이터 캐시는 최대 1 GiB, 교차선 질의 캐시는 최대 128 MiB입니다. 장면 교체와 플러그인 종료 시 해제합니다.

Maya 2025, Ryzen 9 7900X, 말·마차 전체 장면, 스무스 적용, 1920×1080, 2배 샘플링에서 측정했습니다. 장면 열기와 Render View 표시를 제외하고 형상 추출부터 CPU 렌더와 PNG 저장까지 포함했습니다. CPU 컴파일러의 기존 디스크 캐시를 사용했습니다.
