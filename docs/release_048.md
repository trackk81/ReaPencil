# ReaPencil 0.8.48

Windows x64 / Maya 2025용 정식 업데이트입니다. 로컬에서 검증하고 설치한 0.8.48 ZIP과 동일한 파일입니다.

## 주요 변경

- 일반 Preview가 지원되는 재질의 불투명도 텍스처를 자동 인식합니다. 기본 알파 경계 해상도를 최대2048로 높이고 복잡한 구멍·섬의 삼각분할 오류를 수정했습니다. 오브젝트별 수동 설정과 사용자가 지정한 낮은 해상도는 우선 적용됩니다.
- 알파 경계 보간·UV 클리핑을 최적화했습니다. 동일한2048 샘플링의 통제 장면을 별도 Maya 프로세스4회로 비교했을 때 최초 경계 생성·메시 준비 평균12.44초 →6.13초(약51% 단축). 경계·변형 바인딩과 CPU 렌더 PNG는 정확히 동일했습니다. Maya 실행·GPU 업로드·화면 표시 시간은 제외한 수치이며 모든 장면의 속도를 보장하지 않습니다.
- Fast Preview의 소수점 선 두께가 연속적으로 변합니다. 하드/크리즈 에지는 Smooth Mesh Preview 표면을 따라가며, 캐시와 부분 갱신으로 카메라 이동·변형 시 준비 비용을 줄였습니다.
- 일반 Preview 옵션은 뷰포트 성능 설정으로 정리했습니다. 스무스 선과 교차선 계산을 조절할 수 있습니다. 라인 스타일은 Line Window에서 편집합니다.
- 0.8.22 이후 검증한 독립 가시/숨은 선·선 종류별 브러시 곡선, 불투명도·혼합, Merge Groups·렌더 요소·SVG/EPS 합성 및 지원 범위의 거리 감소/참조 연결도 포함합니다. 혼합 SVG/EPS 효과는 래스터 이미지로 포함됩니다.

최종 렌더는 CPU 방식을 유지합니다. 이번 배포에는 미설치 CPU 실험본이 포함되지 않습니다. Pencil+와의 전체 픽셀 일치, 모든 폐곡선 시작점, 일반 비선형 거리 감소 또는 GPU 프리뷰의 CPU 최종 렌더 일치는 보장하지 않습니다. Alpha Cut Prepass 옵션은 계속 제외됩니다.
