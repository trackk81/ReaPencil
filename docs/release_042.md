# ReaPencil 0.8.42 — Fast Preview fractional width

Fast Preview now interpolates adjacent depth-contour radii so fractional width values change coverage continuously. Widths up to2 evaluate one contour ring; exact even widths use one ring, other widths use at most two. Target masks and FXAA remain supported.

This scoped hotfix uses validated0.8.40 CPU/runtime files. Uninstalled CPU041/133 development changes are intentionally excluded. Restart Maya after installation to refresh cached shader programs.

Local installation authorized by the user; no GitHub publication.
