# ReaPencil 0.8.82

연결한 Maya 색 맵·선폭 맵을 CPU 렌더와 일반 **ReaPencil Preview**에서 사용할 수 있습니다. 로컬에서 검증한 알파 렌더 최적화와 브러시 UI 변경도 포함합니다.

- 공통 브러시와 선 종류별 전용 브러시에 Maya 2D 텍스처 연결, 적용량 조절, 기본 텍스처 생성 UI를 추가했습니다.
- 연결된 맵을 우클릭하면 **하이퍼셰이드로 보기**로 해당 노드와 연결을 표시합니다.
- 일반 프리뷰에서 맵, 거친 붓·PNG 붓, 프로필, 대시, 교차선 및 알파 윤곽 조합을 표시합니다. 카메라 이동·회전 중에는 텍스처 샘플과 메시 UV를 다시 계산하지 않으며 맵 편집 시 갱신합니다.
- CPU 렌더는 재질 알파를 읽고 원본 잎 카드를 유지한 채 UV 알파·가림을 판정합니다. 알파 경계 작업과 임시 메모리 사용을 줄였으며 단계별 렌더 진행 표시를 추가했습니다.

검증: 별도 Maya 2025에서 후보 및 설치본 일반 프리뷰를 확인했습니다. 맵 ON/OFF, Fractal·배치 수정, 교차선의 소유 면, 가림, 장면 재개방을 검사했습니다. CPU 맵 렌더 22건은 프리뷰 기능 추가 전 로컬 후보와 픽셀이 동일했습니다. 전체 숲 통제 장면의 기존 로컬 CPU 알파 최적화 측정은 266.82초 → 55.54초였으며 이미지 변경은 없었습니다. 장면과 환경에 따라 시간은 달라집니다.

지원 범위: 2D UV 0–1 단일 타일, 256×256 맵 평가. Fast Preview와 독립 은선 등 일부 legacy 프리뷰 경로에는 맵을 표시하지 않습니다. 3D/카메라 의존 텍스처, UDIM 및 임의 셰이더 네트워크 전체를 지원하는 것은 아닙니다. UV가 없는 알파 면은 불투명하게 유지합니다. 프리뷰와 최종 렌더의 전체 픽셀 일치를 보장하지 않습니다.

Windows x64 / Maya 2025용입니다. 아래 **ReaPencil-0.8.82-Maya2025-Windows-x64.zip** 전체를 풀고 `INSTALL.cmd`를 실행한 뒤 Maya를 다시 시작하세요. 기존 설치본은 ReaPencil 업데이트 메뉴를 사용할 수도 있습니다. GitHub의 Source code ZIP은 설치 패키지가 아닙니다.
