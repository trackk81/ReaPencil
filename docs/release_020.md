# ReaPencil 0.8.20 — 로컬 검토 후보

GitHub 미게시, 설치본 미교체입니다. Windows x64 / Maya 2025용입니다.

## 변경

- 길이에 따라 변하는 선폭·알파 곡선을 CPU 최종 래스터에 연결했습니다. Linear, 저장된 Spline/Bezier/Break 제어점과 좌우 핸들을 평가합니다. 일반 구간의 적응 분할 오차 기준은 1e-6이며, 수치적으로 수직에 가까운 접선은 제한된 1e-4 구간만 허용합니다.
- `Line Set → Brush Details → Width profile (CPU) / Alpha profile (CPU)`에서 제어점 표와 미리보기로 편집합니다. 빈 곡선은 상수 1입니다. Spline 핸들은 저장된 값을 편집하며 원본의 자동 접선 편집 동작은 복제하지 않았습니다.
- 진짜 메시 정점 ID를 이용해 일직선으로 연결된 에지에 획 좌표를 배분합니다. 방향 반전, 이음매 알파 누적 방지 및 화면 클리핑을 처리합니다.
- 가림 판정·곡선 그래프·픽셀 평가를 묶은 네이티브 CPU 경로를 추가했습니다. 곡선을 쓰지 않는 기존 CPU 경로와 샘플링 해상도는 유지합니다. 열린 경계를 하드 에지로 잘못 그리던 경우도 바로잡았습니다.
- Pencil+가 없는 새 Maya 프로세스에서 MA/FOR8 MB 곡선을 복원하고, 변환 후 같은 형식으로 저장·재열기한 CPU 이미지 해시를 확인했습니다.

## 실제 검증

별도 Maya에서 Pencil+ 4.2.3과 14개 사례를 비교했습니다. 지원 범위 13개는 통과했고 제어점 구간 밖으로 핸들이 넘어간 1개 사례는 원본 런타임 차이를 확인해 이관을 명시적으로 제외했습니다. 지원 알파 사례의 측정 지점 최대 차이는 2/255, 선폭 적분값 차이는 최대 약 0.83픽셀입니다. 폭과 알파를 동시에 바꾸는 얇은 끝부분에서는 AA 차이가 더 크므로 픽셀 동등성을 뜻하지 않습니다.

CPU 테스트 122개, 업데이트·번역 테스트 11개 통과. 기존 기본 선 PNG 17개와 말 장면의 기본 렌더·변형 후 이미지는 기존 후보와 동일합니다. 새 네이티브 곡선 배치는 기존 CPU 곡선 경로와 말 장면 4개 이미지가 바이트 단위로 같습니다.

말 전체 장면, 스무스 켬, 1920×1080, 2배 샘플링, 각각 새 Maya 프로세스에서 측정한 단일 실행 기록입니다. 첫 렌더는 패키지 초기화·메시 추출을 포함하며 측정 변동이 있습니다.

| 조건 | 기본 배포본 0.8.19 | 후보 비상수 선폭 | Pencil+ 같은 선폭 곡선 |
|---|---:|---:|---:|
| 최초 | 2.94초 | 2.59초 | 2.40초 |
| 반복 | 1.30초 | 1.17초 | 2.25초 |
| 최대 메시 변형 | 1.51초 | 1.43초 | 2.21초 |
| 전체 메시 변형 | 2.63초 | 2.38초 | 2.25초 |

기본 선과 새 곡선은 다른 스타일이므로 위 표가 동일 이미지 비교는 아닙니다. 기본 선 속도·품질의 회귀는 별도로 확인했습니다. 최초 및 전체 메시 변형 후에는 Pencil+보다 빠르다고 주장하지 않습니다.

## 남은 제한

- 코너·분기·폐곡선 시작점/분할 각도, 교차선 조각의 연결·위상은 아직 원본과 동일하지 않습니다. 일직선 폴리곤 획부터 지원합니다.
- 원본 제어점 구간 밖의 핸들은 자동 이관하지 않습니다. UI에서 보이는 클리핑과 실제 원본 계산이 달랐습니다.
- 비상수 알파는 가시 Normal 브러시 한 개에 한정됩니다. 복수 브러시·독립 숨은 알파·다른 합성 모드는 미구현입니다.
- 거리 감소·폭 랜덤 변화·기존 taper와 곡선의 조합, 곡선의 depth 요소는 명시적 오류를 냅니다. 일반 PNG 요소는 지원하고 SVG/EPS는 생략하며 경고합니다.
- 곡선은 CPU 최종 렌더 기능입니다. 뷰포트는 기존 표현을 사용합니다. MA/MB 복원은 저장 시점 스냅샷이며 절차·연결 애니메이션이나 미저장 편집을 평가하지 않습니다.

압축 해제한 후보의 `INSTALL.cmd`로 직접 검토할 수 있습니다. 이 작업에서는 설치본 교체와 GitHub push/tag/release를 하지 않았습니다.
