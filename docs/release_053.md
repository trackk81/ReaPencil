# ReaPencil 0.8.53

Windows x64 / Maya 2025용 업데이트입니다. 로컬에 설치해 검증한 0.8.53과 런타임 파일이 같습니다.

## 변경 사항

- 고속 프리뷰의 하드 엣지 데이터를 GPU에 유지해 카메라 회전 때 반복 계산·업로드를 줄였습니다. 오브젝트 변형, 이동, 스무스 표면과 라인셋 범위는 계속 반영됩니다.
- 일반 프리뷰에서 고속 프리뷰로 전환할 때 일반 프리뷰를 다시 계산하던 지연을 줄였습니다.
- 대형 장면의 CPU 교차선·가림 판정·메시 준비·선 합성을 최적화했습니다. 검증 장면의 최종 PNG는 이전 버전과 바이트 단위로 같습니다.
- 0.8.48 이후 검증한 도시 장면의 빈 메시 처리, 라인 창 표시, 대형 교차선 처리와 렌더 설정 개선을 함께 포함합니다.

## 검증 범위

도시 통제 장면: 메시 2,696개, 약 691만 삼각형, 스무스 없음. Ryzen 9 7900X / RTX 4070, 뷰포트 1445×797.

- 하드 엣지 약 510만 개를 켠 고속 프리뷰: GPU 완료와 화면 읽기를 포함해 약 31–33fps. 카메라 회전 중 좌표 재읽기·버퍼 재업로드·공간 분할 재생성은 0회였습니다.
- 일반 프리뷰의 검증된 기존 경로: 같은 화면 읽기 조건에서 약 55.6fps.
- 일반 → 고속 전환: 통제 실행에서 39.6초 → 2.8초. 초기 로딩 상태에 따라 달라질 수 있습니다.
- CPU 렌더 2000×1000, 2× 샘플링: 이전 설치본 약 24초 → 약 13초. 같은 조건의 Pencil+는 약 9–10초로, 원본 속도까지는 추가 최적화가 필요합니다.
- CPU 회귀 검사 42개와 별도 Maya의 캐시·스무스·알파 검사 7개를 통과했습니다.

최종 렌더는 CPU 방식을 유지합니다. GPU 프리뷰는 화면 표시용이며 최종 CPU 렌더와 완전히 같지는 않습니다. 모든 장면에서 동일한 FPS나 Pencil+와의 전체 픽셀 일치를 보장하지 않습니다.

## 설치 / 업데이트

기존 설치에서는 **ReaPencil → 업데이트 확인 → 다운로드 및 설치 예약**을 사용하세요. 작업을 저장하고 Maya를 종료한 뒤 설치를 마치고 다시 실행합니다. 다른 PC에서도 GitHub 로그인 없이 업데이트할 수 있습니다.

처음 설치할 때는 **ReaPencil-0.8.53-Maya2025-Windows-x64.zip** 전체를 풀고 **INSTALL.cmd**를 실행하세요. GitHub의 자동 생성 Source code ZIP은 설치 파일이 아닙니다.
