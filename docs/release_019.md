# ReaPencil 0.8.19

Windows x64 / Maya 2025용입니다. 이전 공개 버전 0.8.15 이후의 CPU 렌더 최적화, 커스텀 해상도 수정 및 브러시 호환 개선을 포함합니다.

## 주요 변경

- CPU geometry export, 교차선·가림 처리와 선 rasterization의 네이티브 경로 및 재사용을 개선했습니다. 최초 렌더와 메시 변형 후의 준비 비용을 줄였습니다. 최종 렌더는 CPU 방식입니다.
- ReaPencil 렌더 설정에서 Width/Height 변경 시 정사각 픽셀과 화면 비율을 함께 맞춥니다. 기존 잘못된 비율은 **Use square pixels** 버튼으로 복구합니다. 3000×2000, 2배 샘플링을 검증했습니다. 의도적인 비정사각 픽셀 출력은 여전히 미지원입니다.
- Pencil+ 대시 길이·간격 이관과 별도 CPU 간격을 추가했습니다. 가로 640px 기준 상대 선 크기를 Line별로 반영합니다.
- 일직선 대시 연결 CPU 옵션을 추가했습니다. 원본 split angle 0에만 자동 이관하고, 다른 모서리·폐곡선 위상은 미지원으로 표시합니다.
- 단일 가시 Normal 브러시 불투명도를 CPU PNG·PNG element·SVG에서 지원합니다. 복수/hidden/non-Normal 브러시 합성은 아직 제한됩니다. 반투명 EPS는 미지원 경고를 제공하며 불투명한 선으로 저장하지 않습니다.
- 전체 구간에서 일정한 Linear 폭/alpha profile을 이관합니다. 길이에 따라 변하는 Bezier/Spline 평가와 원본 같은 곡선 편집 UI는 아직 미구현입니다.
- Pencil+ 없이 연 ASCII 및 검증한 Maya 2025 FOR8 MB에서 저장 프로파일을 UUID 기반 snapshot으로 복원합니다. MB는 compact CMPD 배열 형식에 한정되며 sparse DBLE·혼합·다른 저장 형식은 보장하지 않습니다. 저장되지 않은 편집 및 연결 애니메이션/절차 입력은 재평가하지 않습니다.

## 검증과 남은 차이

CPU 회귀 테스트 115개, 별도 Maya의 원본/후보 비교 렌더와 Pencil 플러그인을 로드하지 않은 새 프로세스의 변환·재열기 렌더를 검증했습니다. 기존 기본 선 회귀 이미지 17개는 바이트 단위로 유지됐습니다. 원본과 일부 alpha 반올림, AA·폭·획 위상 차이는 남아 있으며 Pencil+ 전체 기능이나 픽셀 동등성을 보장하지 않습니다.

브러시 옵션의 지원 범위는 CPU 최종 렌더 기준입니다. 뷰포트는 기존 근사 표현을 사용합니다. 원본 설치 파일·스크립트·아이콘·라이선스 기능은 포함하지 않습니다.

## 설치·업데이트

`ReaPencil-0.8.19-Maya2025-Windows-x64.zip` 전체를 압축 해제한 뒤 Maya를 종료하고 `INSTALL.cmd`를 실행하세요. 기존 설치에서는 **ReaPencil → 업데이트 확인 → 다운로드 및 설치 예약**으로 받을 수 있습니다. 설치 후 Maya를 다시 실행합니다. CPU 가속 의존성을 포함해 최초 설치는 오프라인으로 가능합니다.
