# ReaPencil 0.8.13

- 뷰포트 Renderer 메뉴에 **ReaPencil Preview / ReaPencil Fast Preview**를 등록하고, 각 항목 오른쪽 옵션 버튼에서 설정을 엽니다.
- **ReaPencil 설정…**에서 English / 한국어를 선택합니다. 메뉴·라인 창·속성 편집·프리뷰 설정의 표시 언어를 정리하고 사용자 환경설정에 저장합니다.
- 고속 프리뷰에 **FXAA / 끄기** 선택을 추가했습니다.
- 고속 프리뷰도 활성 라인셋의 오브젝트·재질 대상을 반영합니다. 같은 메시의 재질별 면 제한, 대상 추가·제거·비활성화, 가림과 격리를 반영합니다.
- 고속 프리뷰 옵션에 **하드 에지 / 크리즈 지정 에지**를 추가했습니다. 크리즈는 면 각도가 아니라 **Maya edge crease 값이 0보다 큰 에지**입니다. 두 옵션은 기본적으로 꺼져 있습니다.
- 표시할 에지의 연결 정보는 캐시하며, 옵션을 켰을 때 지정 에지가 있는 대상 메시의 변형 좌표를 추가로 읽습니다. 이 추가 비용은 장면에 따라 달라집니다. 기본 화면 공간 프리뷰는 유지합니다.
- 최종 CPU 렌더 방식과 원본 사용자 장면은 변경하지 않았습니다.

실제 Maya 2025 / RTX 4070 / 1757×1044 뷰포트에서 스무스 없는 리깅 장면의 가슴 컨트롤을 40프레임씩 움직이며 GPU 완료와 RGB 화면 변화를 확인했습니다. 복사본에서 크리즈 7,152개·하드 에지 25,824개가 포함된 대상으로 검사한 결과입니다.

| 표시 옵션 | 표시 FPS |
|---|---:|
| 두 옵션 끄기 | 29.8 |
| 크리즈 지정 에지만 | 26.2 |
| 하드 에지만 | 23.9 |
| 둘 다 켜기 | 24.0 |
| 다시 두 옵션 끄기 | 29.6 |

평평한 면의 지정 에지가 실제로 표시되고, 옵션을 끄거나 크리즈 값을 제거하면 사라지는 것을 검사했습니다. 가림·격리와 라인셋 대상 제한도 검사했습니다. 모든 리깅이나 장면의 FPS를 보장하지는 않습니다. 고속 프리뷰의 화면 공간 교차선·브러시는 정밀 모드와 다를 수 있습니다.

표시 보조 모듈은 **reaPencilFast094.mll**이며 메인 플러그인이 자동으로 불러옵니다. 업데이트 적용 후 Maya를 다시 실행하세요.
