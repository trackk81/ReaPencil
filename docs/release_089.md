# ReaPencil 0.8.9

리깅 조작을 위한 **고속 GPU 프리뷰**를 별도 옵션으로 추가했습니다. Maya가 그린 깊이 이미지에서 GPU 셰이더가 선을 생성합니다. 프리뷰를 갱신할 때 메시 정점 추출, 삼각형 교차 검사, CPU로 선 좌표를 읽어오는 과정을 거치지 않습니다.

- **ReaPencil → 고속 GPU 프리뷰 켜기**로 사용합니다.
- **고속 프리뷰 설정…**에서 선 굵기·색상·면 꺾임 기준을 조절하면 즉시 반영됩니다.
- **Enable live viewport lines (Precise)**로 기존 정밀 GPU 방식에 돌아갑니다. **Disable live viewport lines**는 두 방식 모두 끕니다.
- 배경색, 리깅 컨트롤, Isolate Select, 직교 카메라를 유지합니다. 평평한 면의 깊이 오차가 잔선이 되는 것을 걸러냅니다.
- 고속 프리뷰는 화면에 보이는 모든 표면에 하나의 스타일을 적용합니다. 교차선은 화면상의 근사이며 개별 라인셋, 재질 경계, 숨은 선, 고급 브러시를 정확히 재현하는 모드가 아닙니다. 투명 표면은 Maya의 깊이 기록 여부에 따라 표현이 제한됩니다.
- Windows / Maya 2025의 Viewport 2.0 **OpenGL Core Profile**용입니다. 추가 표시 모듈은 **reaPencilFast089.mll**이며 선택 시 자동으로 불러옵니다. 기존 정밀 표시 모듈은 **reaPencilDraw088.mll**입니다.
- **최종 CPU 렌더와 장면의 스무스·리깅 설정은 변경하지 않습니다.**

실제 Maya 2025 / RTX 4070 / 1757×1044에서 스무스 없는 리깅 장면의 컨트롤을 40프레임씩 움직이고 GPU 완료와 화면 변화를 확인했습니다.

| 조작 | 기존 정밀 표시 | 고속 프리뷰 | 라인 끄기 |
|---|---:|---:|---:|
| 가슴 컨트롤 변형 | 15.4fps | 32.7fps | 34.3fps |
| Root 컨트롤 회전 | 9.3fps | 15.5fps | 16.0fps |

프리뷰 켜기는 약 0.71초에서 0.06초로 줄었습니다. 이 장면의 Root 조작은 라인을 꺼도 약 16fps이므로, 모든 동작이 30fps 이상이 된 것은 아닙니다. 리깅 자체의 평가 비용은 별도로 남아 있습니다. 원본 장면은 저장하지 않았습니다.
