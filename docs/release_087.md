# ReaPencil 0.8.7

- GPU 뷰포트에서 가려진 선이 표면 앞으로 새어 나오는 깊이 판정을 수정했습니다. 브러시 폭 안의 면 깊이를 적용하기 전에 선 중심이 실제 표시 표면에 가려졌는지 검사합니다. MSAA 화면에서는 하드웨어 중심선 깊이 판정을 사용합니다.
- Isolate Select에서 해당 패널에 포함된 객체와 그룹의 선만 표시합니다. 교차선은 양쪽 원본 객체가 모두 표시되는 경우에만 남습니다. 격리를 해제하면 전체 선이 복원됩니다.
- 같은 카메라를 사용하는 여러 패널에도 각각의 격리 목록을 적용합니다. GPU 선 버퍼는 공유하여 패널마다 복제하지 않습니다. 고급 브러시의 기존 GPU 경로도 격리된 객체를 기준으로 계산합니다.
- GPU 표시 보조 모듈은 **reaPencilDraw087.mll**입니다. 메인 플러그인 **reaPencil.py**가 자동으로 불러옵니다. 업데이트 후 Maya를 다시 실행하세요.
- CPU 최종 렌더 방식은 유지합니다. 사용자 장면은 수정하거나 저장하지 않습니다.

실제 Maya 2025에서 제공된 장면의 잔선 영역, 카메라 회전, MSAA 4, 패널별 격리, 그룹 격리, 교차선 숨김과 복원을 검사했습니다. 특정 장면의 검증 결과이며 모든 장면의 선 품질을 보장하는 것은 아닙니다.
