# ReaPencil 0.8.66 — 고해상도 CPU 렌더 메모리 개선

Maya 2025 / Windows x64용 업데이트입니다. 검토한 로컬 0.8.66과 같은 런타임을 배포합니다.

- 이미지 가로·세로의 4096픽셀 제한과 고정 32Mi 샘플 제한을 제거했습니다. Common 탭의 해상도를 사용하며, 샘플링 값을 자동으로 낮추지 않습니다.
- 큰 이미지의 축소·RGB/알파 변환·PNG 저장을 행 단위로 처리하고, 사용이 끝난 일회용 깊이 버퍼를 먼저 해제해 중간 배열의 메모리 피크를 줄였습니다. CPU 샘플 위치·정밀도·선 계산과 기존 렌더 커널은 유지합니다.
- Maya Render View의 별도 8192픽셀·16Mi 픽셀 표시 제한도 제거했습니다. 새 표시 모듈은 64행 단위로 RGB와 알파를 업로드합니다.
- 메모리 사전 검사는 유지하되, 가용 RAM의 20%에 256MiB를 더 남기던 과도한 여유분을 **가용 RAM의 20%, 최대 512MiB**로 조정했습니다. 오류에는 실제 가용량·검사상 사용 가능량·여유분을 표시합니다. 정수 범위 검사도 유지합니다.

## 실제 Maya 검증

말·마차 장면 복사본에서 **6000×5000, 오버샘플링 2**(내부 12000×10000 샘플) CPU 렌더를 완료했습니다. 측정 프로세스의 최대 실제 RAM 사용량(working set)은 약 **5.75GiB**, 최대 private commit은 약 **8.63GiB**였습니다. 두 값은 서로 다른 메모리 지표입니다. 렌더 호출은 장면 내보내기를 포함해 약 10초였으며, 모든 장면·구도의 속도나 메모리를 보장하는 값은 아닙니다.

기존 버전과 비교한 장면의 PNG·보조 출력은 바이트 단위로 일치했습니다. float32/float64, 샘플링 1~4, 좁거나 홀수 높이의 이미지와 RGB/알파 변환을 포함한 48개 행 단위 저장 대조 검사도 통과했습니다. 기존 CPU 기준 렌더 PNG는 동일합니다.

실제 Maya Render View에서 가로·세로 각각 9000픽셀 출력과 4200×4100 이미지를 표시하고 저장한 RGBA 픽셀이 원본과 완전히 일치했습니다. 배포 런타임 136개는 검토한 로컬 설치본과 일치합니다. 0.8.63의 알파 오류 분리·오류 목록·뷰포트 선택 방해 수정도 포함됩니다.

## 메모리 검사와 남아 있는 범위

**RAM 예상량에 따른 차단 검사는 여전히 있습니다. 경고만 표시하고 진행하는 버전은 아닙니다.** 가용 메모리 입력을 보수적으로 7.51GiB에서 시작하도록 조정한 별도 Maya 대조에서도 같은 6000×5000·샘플링 2 출력이 생성됐습니다. 이는 검사 입력의 모의 조건이며, 운영체제의 RAM을 실제로 그 용량에 제한한 시험은 아닙니다.

복잡한 장면, 숨은 선·합성용 추가 버퍼, 여러 렌더 요소에는 더 많은 메모리가 필요할 수 있으며 여전히 렌더가 차단될 수 있습니다. 메모리 추정은 실제 사용량을 보장하지 않습니다. 기존 렌더 요소별 용량 검사와 0.8.61의 곡선 표시 지원 범위·성능 한계도 유지합니다.
