# ReaPencil 0.8.35 — local candidate

Full-domain constant Linear reduction curves can now be imported even when Pencil reference-object mode is enabled. Controlled original renders establish this constant subset is independent of reference position, missing reference, pivots, locator shape offset and parent transforms. Existing CPU multiplier rendering remains unchanged. Unknown-node MA/MB recovery now permits only the verified rsObject message connection from a transform while continuing to reject other incoming inputs.

Distance-varying reference reduction is still explicitly unsupported. The source world-origin metric was investigated, but a live native reference-distance renderer has not been added. Existing constant width/AA approximation remains.

No automatic installation or GitHub publication.
