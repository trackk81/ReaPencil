# ReaPencil 0.8.5

- 기본 Maya 플러그인 파일을 **reaPencil.py**로 변경했습니다. **reaToon.py**는 기존 장면을 여는 호환 연결 파일로 남겼습니다. 기존 Auto load 선택은 새 파일로 이전합니다.
- ReaPencil 메뉴에 **업데이트 확인… / 업데이트 설치…**를 추가했습니다. `trackk81/ReaPencil` 공개 GitHub Releases에서 정식 Maya 2025 Windows x64 배포본을 받습니다. 다른 PC에서 GitHub 로그인 없이 사용할 수 있습니다.
- 다운로드 및 모든 내부 파일을 검증한 뒤 설치를 예약합니다. 모든 Maya 종료를 기다리며, 완료 알림 후 Maya를 다시 실행하면 적용됩니다. 교체 실패 시 이전 파일을 복구합니다.
- CPU 렌더와 0.8.4의 GPU 표시 방식은 유지합니다.

처음에는 이 버전의 ZIP 전체를 압축 해제하고 `INSTALL.cmd`를 실행하세요. 이후 새 버전은 메뉴에서 설치할 수 있습니다. GitHub의 Source code ZIP은 설치 배포본이 아닙니다.
