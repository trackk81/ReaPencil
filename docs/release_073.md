# ReaPencil 0.8.73

라인 패턴과 브러시 스트로크 모두 PNG를 불러오고, 사용자 프리셋으로 추가·편집·저장할 수 있습니다. 투명 PNG는 알파, 흰 배경 이미지는 어두운 잉크로 자동 인식합니다. 색은 라인셋을 따르며 이미지 마스크는 장면/프리셋에 포함됩니다.

- 라인 PNG 6개: 화살표, 물결, 지그재그, 바느질, 고리, 점과 대시.
- 브러시 PNG 6개: 잉크, 마른 붓, 목탄, 부드러운 붓, 붓결, 닳은 잉크.
- `examples/PNGPatterns`에 개별 PNG, 한글 안내, 비교 이미지와 Maya 예제 씬을 포함했습니다. 예제 전용 ZIP도 제공합니다. 예제 아트워크는 CC0입니다.
- 0.8.67–0.8.72의 메시 표면 그리기(테스트), 필압/지우개/손떨림 보정, 실시간 그리기 피드백, 라인·브러시 프리셋 편집과 수치 슬라이더가 포함됩니다.

Maya 2025 별도 프로세스에서 12개 PNG 불러오기, 장면 저장·재열기, CPU 렌더를 확인했습니다. 앞선 별도 GUI 검증에서 PNG 일반 프리뷰와 프리셋 저장을 확인했습니다. 기존 기본 CPU 렌더 골든 해시는 유지됩니다. 이번 예제 추가는 설치된 0.8.73의 153개 런타임 파일을 변경하지 않습니다.

## 사용

라인셋의 **선 형태 / 브러시 프리셋** 창에서 **라인 PNG 불러오기** 또는 **브러시 PNG 불러오기**를 선택하세요. 일반 프리뷰/CPU 렌더에서 확인합니다. PNG 예제 ZIP의 `README_KO.md`에 권장 간격·높이·선폭이 있습니다. `PNG_Examples_073.ma`는 12개가 이미 적용된 비교 씬입니다. 플러그인을 먼저 로드한 뒤 열고 persp 카메라로 렌더하세요.

## 한계

고속 프리뷰와 일부 기존 폴백 경로는 PNG 효과를 완전히 표시하지 않습니다. 원본은 최대4096px/변, 내부 마스크는 최대512px/변이며 색상 이미지를 그대로 렌더하지 않습니다. 일반 프리뷰와 CPU의 안티앨리어싱은 픽셀 단위로 같지 않습니다. 큰 패턴은 추가 계산 비용이 있습니다. 압력/복잡한 곡선/숨은 선/병합 그룹/벡터 출력의 모든 조합을 보증하지 않으며, 메시 위 직접 그리기는 테스트 기능입니다. 설치 ZIP은 Windows x64 / Maya 2025 전용입니다.
