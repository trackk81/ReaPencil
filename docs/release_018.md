# ReaPencil 0.8.18 — 커스텀 해상도 수정 (로컬 검증본)

ReaPencil 렌더 설정의 가로·세로 입력에서 Maya 화면 비율과 픽셀 비율을 함께 갱신하도록 수정했습니다. 기존 입력은 오래된 화면 비율을 남겨, 3000×2000 같은 크기에서 픽셀 비율이 1.185로 바뀌면 정사각 픽셀 제한에 걸릴 수 있었습니다.

- ReaPencil 탭에서 Width/Height를 바꾸면 Pixel Aspect Ratio를 1, Device Aspect Ratio를 Width/Height로 맞춥니다.
- 기존 장면의 잘못된 비율은 **Use square pixels** 버튼으로 복구합니다. 가로·세로 크기는 유지합니다.
- 일반 화면 비율과 픽셀 비율은 별개입니다. 3000×2000 같은 직사각형 이미지도 지원합니다. 의도적인 비정사각 픽셀 출력은 여전히 지원하지 않으며 렌더 시 장면 값을 몰래 바꾸지 않습니다.
- 숨은 선이 꺼져 있으면 전체 크기 숨은 선 버퍼를 만들지 않습니다. Merge Groups가 없으면 소유 메시 이미지도 만들지 않습니다. 보조 출력의 빈 숨은 선 이미지는 최종 해상도로 만듭니다.
- CPU 샘플 한도는 32 Mi samples로 통일했습니다. 3000×2000, 2배 샘플링의 24M samples를 지원하며, 안티앨리어싱 수준을 자동으로 낮추지 않습니다. 최대 가로·세로 4096 제한은 유지합니다.

실제 Maya 2025에서 스무스가 적용된 말·마차 전체 장면을 3000×2000, 2배 샘플링으로 렌더했습니다. 약 2.56초가 걸렸으며 RGB와 알파가 있는 PNG를 확인했습니다. 원본 장면은 변경하지 않았습니다. 1920×1080 출력은 0.8.17과 바이트 단위로 일치했습니다.

별도 Maya GUI에서 실제 키 입력으로 Width/Height 변경과 복구 버튼을 검사했습니다. 기본 attrControlGrp의 콜백이 실행되지 않는 문제를 재현한 뒤 명시적인 정수 입력 필드로 수정했습니다. CPU 회귀 테스트 95개가 통과했습니다.

설치 후 Maya를 다시 실행하고, 기존 값이 1.185로 남아 있다면 ReaPencil Render Settings 탭에서 Use square pixels를 한 번 누르세요. GitHub에는 게시하지 않았습니다.
