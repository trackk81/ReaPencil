# ReaPencil 0.8.34 — local candidate

Pencil distance reductions with redundant, ordered Linear control points along a single full-domain straight line can now be imported into the existing native CPU endpoint path. A bounded 1e-7 normalized tolerance covers stored control-point quantization. Both width and alpha, independent hidden channels and dedicated brushes are supported. Source MA/MB numeric snapshots use the same recognition.

Bent piecewise curves, non-Linear/partial-domain curves and reference-object reduction remain unsupported. This is canonicalization of a verified subset, not arbitrary multi-knot evaluation. Existing default CPU math, DLL and width/AA approximations are unchanged.

No automatic installation or GitHub publication.
