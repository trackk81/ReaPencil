# ReaPencil 0.8.77

Maya 2025 / Windows x64

## 주요 수정

- **대시 + 거친 붓 → 기본 브러시 전환 후 일반 프리뷰가 멈추던 문제를 수정했습니다.** 기본 브러시는 독립된 대시 선 형태를 유지합니다. 대시만 남은 경우도 일괄 계산과 카메라 이동 중 표시 재사용을 적용합니다.
- 붓 스트로크 사용 중 카메라 이동을 최적화하고, 멈춘 뒤 현재 시점의 상세 표시를 백그라운드에서 갱신합니다. 프리뷰 성능 설정의 **붓 스트로크·대시 사용 중 카메라 이동 최적화**에서 제어합니다.
- 0.8.73 이후 로컬 검증한 붓 일괄 처리, 카메라 이동 최적화, 상세 갱신 가속을 포함합니다. PNG 라인·브러시 프리셋과 기존 예제도 유지합니다.

## 검증과 범위

- 별도 Maya 2025의 dd.mb 통제 장면에서 대시 + 거친 붓 → 기본 브러시 전환: 약 **9.01초 → 0.79초**. 이미 붓 계산 중이면 약 **1.77초**. 이후 스크립트 카메라 이동은 약 **44fps**였습니다. 화면 크기·장면·하드웨어에 따라 달라집니다.
- 175개 실제 입력 묶음 / 445,251개 대시 선분의 수·좌표·메타데이터가 기존 계산과 일치합니다. 계산 중 전환, 오래된 결과 폐기, 혼합 스타일, Undo/Redo를 확인했습니다.
- **CPU 렌더 방식과 품질을 유지합니다.** dd.mb CPU 결과 해시는 이전 검증본과 같습니다. 이번 변경은 일반 프리뷰에 적용되며 고속 프리뷰 변경은 없습니다.
- 붓을 실선으로도 되돌리려면 **선 형태 → 실선(기본)**을 별도로 선택하세요. 이 버전은 대시를 임의로 끄지 않습니다.

## 설치

아래 `ReaPencil-0.8.77-Maya2025-Windows-x64.zip`을 받아 전체 압축을 풀고 `INSTALL.cmd`를 실행한 뒤 Maya를 다시 시작하세요. GitHub 자동 생성 Source code ZIP은 설치 패키지가 아닙니다. 기존 설치에서는 ReaPencil 업데이트 메뉴도 사용할 수 있습니다.

PNG 예제와 사용법은 [저장소의 PNGPatterns](https://github.com/trackk81/ReaPencil/tree/v0.8.77/examples/PNGPatterns)에 있습니다.
