# ReaPencil 0.8.15

- 오브젝트 추가 목록에서 **현재 라인셋에 이미 등록된 오브젝트**를 제외합니다. 메시 셰이프와 부모 오브젝트 이름을 같은 대상으로 판정합니다.
- 쉐이더 추가 목록에서도 **현재 라인셋에 이미 등록된 쉐이더**를 제외합니다.
- 등록을 제거하면 추가 목록에 다시 나타납니다. 다른 라인셋에만 등록된 대상은 현재 라인셋에 계속 추가할 수 있습니다.
- 면이나 에지만 부분적으로 등록된 메시에는 전체 오브젝트를 추가할 수 있습니다.
- 렌더링 및 뷰포트 계산 방식은 변경하지 않았습니다.

실제 Maya 2025에서 등록·제거·재등록과 다른 라인셋 대상의 표시를 검사했습니다. 업데이트 적용 후 Maya를 다시 실행하세요.
